#  Приложение для анализа транзакций
Приложение будет генерировать JSON-данные для веб-страниц,
формировать отчеты в формате Excel, а также предоставлять другие сервисы.

По состоянию на 12.02.2026 проект находится в разработке.

Структура приложения:
1. Веб-страницы:
- Главная
- События
2. Сервисы:
- Выгодные категории повышенного кешбэка
- Инвесткопилка
- Простой поиск
- Поиск по телефонным номерам
- Поиск переводов физическим лицам
3. Отчеты:
- Траты по категории
- Траты по дням недели
- Траты в рабочий/выходной день

## Установка приложения
1. На данной стадии разработки для использования приложения необходимо установить `PyCharm`.
2. Клонируйте репозиторий с [GitHub](https://github.com/Dasha0Ramzer/transaction-analysis-application).
3. Установите зависимости:
```
poetry install
```
4. Получите API-ключи на [api.apilayer.com](https://api.apilayer.com) и на [api-ninjas.com](https://api-ninjas.com),
скопируйте файл `.env.example` и вставьте свои API-ключи.

## Разработка
Основные функции для генерации JSON-ответов реализованы в отдельном модуле `views.py`.

Вспомогательные функции реализованы в модуле `utils.py`.

По состоянию на 12.02.2026 в проекте реализованы следующие функции:

- **Модуль `utils.py`:**

1. Функция, возвращающая приветствие в соответствии с временем суток.
2. Функция, считывающая XLSX-файл и выводящая содержимое.
3. Функция, фильтрующая транзакции в диапазоне с начала месяца по текущий день.
4. Функция, выдающая номера всех карт.
5. Функция, суммирующая расходы за месяц.
6. Функция, рассчитывающая кэшбэк, исходя из суммы расходов.
7. Функция, возвращающая ТОП-5 транзакций по сумме операции.
8. Функция, возвращающая курс валют из файла `user_settings.json`.
9. Функция, возвращающая курс акций из файла `user_settings.json`.

- **Модуль `views.py`:**

1. Функция, "собирающая" все вспомогательные функции для вывода данных для веб-страницы "Главная".
2. Функция, записывающая JSON-ответ в файл для страницы "Главная".

### Страница "Главная"
Реализован набор функций и главная функция, принимающая на вход строку с датой и временем в формате 
`YYYY-MM-DD HH:MM:SS` и возвращающая JSON-ответ со следующими данными:

1. **Приветствие** в формате "???", где ??? — «Доброе утро» / «Добрый день» / «Добрый вечер» /
«Доброй ночи» в зависимости от текущего времени.
2. **По каждой карте:**
- последние 4 цифры карты;
- общая сумма расходов;
- кешбэк (1 рубль на каждые 100 рублей).
3. **Топ-5 транзакций по сумме платежа.**
4. **Курс валют.**
5. **Стоимость акций из S&P500.**

## Тестирование
Проект использует библиотеку `pytest` для тестирования.
Все основные модули проекта покрыты тестами, что позволяет обеспечивать стабильность
и надежность кода. Тесты находятся в папке `tests`, и их можно запустить командой:
```pytest --cov=src --cov-report=html```

### Покрытие тестами
- Покрытие тестами составляет 92%.
- Основные модули, такие как `utils` и `views` имеют высокий уровень покрытия,
подтверждающий корректность их работы.
- Отчет о покрытии можно найти в папке `htmlcov`, открыв файл `index.html` в браузере.

### Подробности
- Тесты включают проверку всех критических функций.
- Используются параметризированные тесты и фикстуры для различных сценариев.
- Тестирование с Mock и patch.
