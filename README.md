## Установка
1. Клонируйте репозиторий с [GitHub](https://github.com/Dasha0Ramzer/transaction-analysis-application).
2. Установите зависимости:
```commandline
poetry install
```
3. Скопируйте `.env.example` и укажите API-ключи
([api.apilayer.com](https://api.apilayer.com),
[api-ninjas.com](https://api-ninjas.com)).
4. В `user_settings.json` задайте валюты и акции.
5. Поместите файл `operations.xlsx` в папку `data/`.

## Функционал
### Веб-страницы (`views.py`)
**«Главная»** — принимает дату/время `YYYY-MM-DD HH:MM:SS`,
возвращает JSON:
- приветствие по времени суток;
- по каждой карте: последние 4 цифры, сумма расходов, кешбэк (1 ₽ на 100 ₽);
- топ-5 транзакций по сумме;
- курсы валют и цены акций.

**«События»** — принимает дату и диапазон (`W`/`M`/`Y`/`ALL`,
по умолчанию — месяц), возвращает JSON:
- расходы (общая сумма, топ-7 категорий + «Остальное», «Наличные»/«Переводы»);
- поступления (общая сумма, по категориям);
- курсы валют и цены акций.

### Сервисы (`services.py`)
|Сервис|                         Описание                         |
|:-----|:--------------------------------------------------------:|
|Выгодные категории кешбэка| Анализ потенциального кешбэка по категориям за год/месяц |
|Инвесткопилка|Сумма отложенных средств через округление трат (порог 10/50/100 ₽)|
|Простой поиск|Транзакции с запросом в описании или категории|
|Поиск по телефонам|Транзакции с мобильными номерами в описании|
|Поиск переводов физлицам|Транзакции категории «Переводы» с именем и инициалом фамилии|

### Отчеты (`reports.py`)
- **Траты по категории** — за последние 3 месяца от указанной/текущей даты.
- **Траты по дням недели** — средние траты по каждому дню недели за 3 месяца.
- **Траты в рабочий/выходной день** — средние траты за 3 месяца.

Результаты отчётов сохраняются в файл через декоратор (с параметром имени файла или по умолчанию).
